1. Présentation de l'application

NutriProof permet d'extraire, relire et exporter les données de documents de suivi clinique à partir de formulaires numérisés. L'outil supporte surtout deux familles de documents :

  • Bilan lipidique : résultats biologiques et analyses de laboratoire ;
  • Formulaire de suivi : contexte clinique, phase, visite, participant et réponses structurées d'un questionnaire.

L'application combine OCR, validation visuelle et correction manuelle pour garantir que les données exportées correspondent au bon format métier.

Fonctionnalités principales

  • Téléversement de PDF ou de pages scannées ;
  • Extraction automatique selon le type de formulaire ;
  • Visualisation interactive des zones OCR ;
  • Révision des valeurs directement dans la grille ;
  • Copie des valeurs de la page précédente pour les formulaires de suivi ;
  • Export Excel/CSV dans le bon format métier.

4. Téléverser un document

Au lancement, vous accédez à la page principale de gestion des documents.

1
Sélectionnez le document à traiter depuis votre ordinateur ou glissez-déposez un fichier compatible.
2
Le système détecte automatiquement le type de formulaire (bilan lipidique ou formulaire de suivi).
3
L'OCR est lancé et la page de révision s'ouvre pour inspection et correction.
Pour les formulaires de suivi, le contexte de visite (phase, visite, date et participant) est priorisé afin d'aligner les données métier, même si plusieurs pages sont traitées ensemble.

5. Révision et correction

La page de révision affiche, à gauche, le tableau des valeurs extraites et, à droite, l'image du document avec les zones OCR.

Tableau de révision

  • Chaque ligne représente un paramètre ou une question du document ;
  • La colonne Paramètre affiche le libellé métier ;
  • La colonne Valeurs éditées permet la correction directe ;
  • Les valeurs vides ou non pertinentes peuvent être ajustées avant export.

Cas particulier : Formulaire de suivi

Pour le formulaire de suivi, l'interface tient compte du contexte de la page et des données de visite. Les éléments suivants sont particulièrement importants :

  • Phase et Visite : utilisés pour regrouper les données par suivi ;
  • Date d'observation : mémorisée et alignée avec le bon participant ;
  • No du participant : identifiant utilisé comme clé de fusion ;
  • Copier : bouton permettant de recopier les valeurs de la page précédente pour accélérer la saisie.
Les métadonnées internes de traitement (index de page, index de document, etc.) ne sont pas montrées à l'utilisateur final et ne doivent pas être prises comme données métier.

6. Validation

La validation se fait directement après la révision, avant l'export final.

  • Vérifiez que les libellés et valeurs correspondent bien au document réel ;
  • Contrôlez les numéros de participant et les données de visite ;
  • Validez les pages ou documents lorsque la revue est terminée.

Le statut de validation est sauvegardé automatiquement pour chaque document.

9. Dépannage

L'OCR ne détecte pas certaines lignes

  • Assurez-vous que le document est lisible, bien contrasté et numérisé avec une résolution suffisante ;
  • Les documents flous ou inclinés peuvent affecter la lecture ;
  • Les éléments très petits ou très proches peuvent demander une correction manuelle.

Les valeurs extraites sont incorrectes

  • Utilisez la page de révision pour corriger les cellules directement ;
  • Vérifiez que la bonne phase/visite/participant est associée à la page ;
  • Utilisez la fonction de copie de la page précédente pour les formulaires de suivi répétitifs.

Le document ne s'exporte pas correctement

  • Vérifiez que les données obligatoires sont complètes ;
  • Contrôlez la cohérence des clés métier (participant, phase, visite, date) ;
  • Relancez la révision avant export final si certains champs sont vides ou incohérents.
